# Mini Task Tracker

## Project Description
Mini Task Tracker is a Python-based command-line application that helps users manage daily tasks. Users can add, view, complete, and delete tasks. The application uses JSON file handling to save and load tasks between sessions.

## Features
- Add, view, complete, and delete tasks.
- Save and load tasks using `tasks.json`.
- Validate user input and handle file errors.

## Technologies Used
- Python
- JSON

## How to Run
1. Install Python.
2. Open the project in PyCharm.
3. Run `mini_task_tracker.py`.
4. Follow the menu options to manage tasks.

## Learning Outcomes
This project demonstrates Python functions, loops, conditional statements, lists, dictionaries, exception handling, and JSON file handling.
